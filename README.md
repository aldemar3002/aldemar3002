### 📌 Featured projects

- **[XRCX Puzzlebot ROS 2 Workspace](https://github.com/aldemar3002/XRCX_Puzzlebot_ROS2)** — ROS 2 (Humble) workspace for a differential-drive Puzzlebot: SLAM mapping with `slam_toolbox` and autonomous navigation with Nav2, simulated in Gazebo and tuned through AMCL, costmap, and controller parameters. Built with a 4-person team.
- **[Plant Vigor Detection — Segmentation_NDVI](https://github.com/aldemar3002/Segmentation_NDVI)** — Computer vision / deep learning system that estimates a plant's vigor as an NDVI proxy in real time from RGBD camera input (color + depth). Uses a **multispectral U-Net CNN** for pixel-level semantic segmentation, trained with PyTorch + PyTorch Lightning, with spectral index feature engineering (ExG, VARI, GLI) feeding the model.
- **[ArtificialVision-MQTT (PickMate)](https://github.com/aldemar3002/ArtificialVision-MQTT)** — IoT pick-and-place system combining **computer vision** with embedded control: an ESP32 and sensors (DHT11) publish/subscribe over MQTT to drive a robotic claw and motors, while a Python/Raspberry Pi client handles vision-based detection and communication logic.
- **[Embedded Inclusive Educational Assistance System](https://github.com/aldemar3002/Embedded-inclusive-educational-assistance-system)** — Accessibility-focused assistant combining **computer vision, NLP, and speech recognition** via Google Cloud APIs: real-time video/frame analysis, OCR, scene description, Spanish voice commands, text-to-speech, and translation.
