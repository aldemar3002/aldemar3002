### 📌 Featured projects

- **[XRCX Puzzlebot ROS 2 Workspace](https://github.com/aldemar3002/XRCX_Puzzlebot_ROS2)** — ROS 2 (Humble) workspace for a differential-drive Puzzlebot: SLAM mapping with `slam_toolbox` and autonomous navigation with Nav2, simulated in Gazebo and tuned through AMCL, costmap, and controller parameters. Built with a 4-person team.
- **[Plant Vigor Detection — Segmentation_NDVI](https://github.com/aldemar3002/Segmentation_NDVI)** — Computer vision system that estimates a plant's vigor as an NDVI proxy in real time from RGBD camera input (color + depth), using a multispectral U-Net segmentation model built with PyTorch.
- **[ArtificialVision-MQTT (PickMate)](https://github.com/aldemar3002/ArtificialVision-MQTT)** — IoT pick-and-place system: an ESP32 and sensors (DHT11) publish/subscribe over MQTT to control a robotic claw and motors, with a custom interface and a Python/Raspberry Pi client handling the vision and communication logic.
- **[Embedded Inclusive Educational Assistance System](https://github.com/aldemar3002/Embedded-inclusive-educational-assistance-system)** — Accessibility-focused assistant using Google Cloud APIs to analyze video in real time: frame extraction, OCR, computer vision descriptions, Spanish voice commands, text-to-speech, and translation.
